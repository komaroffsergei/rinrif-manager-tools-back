# Устройство и запуск

Java backend служебных инструментов GitCut и ATR2Spec.

## Основные возможности

- Поиск изменений в GitLab
- Подготовка черновика постановки из АТР
- API, модели и отчёты трассировки релизов

## Состав

Стек: Java, Maven. Базовая ветка документации: `dev`.

В исходниках: 41 файлов `.java`, 3 файлов `.yml`.


## Запуск

Используйте JDK и Maven, совместимые с исходным `pom.xml` и Jenkinsfile. Настройки приватных репозиториев и сервисов задаются вне Git. Структура модулей и команды CI сохранены в исходниках; серверные сервисы в ходе архивирования не запускались.
